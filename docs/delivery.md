## 明确限制与后续工作

- PDF 使用 pypdf；双栏、公式与作者提取为启发式。未实现 GROBID、Crossref/Semantic Scholar/OpenAlex 自动补全和 OCR 自动预处理（T1.9/T1.10/T3.7）。空白 PDF 会返回 OCR 提示。
- TF-IDF 为词法基线；真实语义能力需要 `semantic` extra 与本地模型。未内置或自动下载语义模型，不宣称跨语言语义质量指标已通过。
- 分类命名使用关键词，官方大纲使用本地模板；没有 LLM 自动主题命名或大纲内容推理。大纲中的引用是阅读建议，不声称论文证明了模板论点。
- `outline-from-draft` 当前是草稿结构检查模板，不解析用户草稿层级。第三方插件当前只提供 read_library/read_topics；它是可信代码，不是权限沙箱。未实现线上插件索引与远程分发（T5.9）。
- 转换保真度、CSL 样式以及自定义模板须由本机 Pandoc/LibreOffice/XeLaTeX 验证；未附带期刊/学校模板或 APA/IEEE/GB/T CSL 文件。LaTeX→PDF 通过 Pandoc 清洗并重建，而不是执行原文 latexmk。
- 双语按稳定分块配对，长段落可能被拆成多个分块；术语表在提示词中注入并生成缺词告警，不承诺 95% 的人工质量指标。
- 遍历、分块、外部调用支持协作式取消；同步解析超大文件无法保证 5 秒终止。扫描任务可恢复为重新增量扫描，批量转换与翻译使用检查点。
- P2：目录监听、MCP Sampling、外部 MCP 翻译后端、学术润色尚未实现（T1.11/T4.12/T4.13）。
- 待使用真实且可合法使用的多格式 50 篇文献样本评估标题/摘要准确率、聚类纯度、千篇扫描性能与内存，再决定 1.0.0 验收。
- 未发布 PyPI。当前可本地安装、构建 wheel 或使用 `uvx --from <本地项目路径>`；发布需要独立的版本和账号操作。

## 本机验证

详见 [验证记录](validation.md)。测试使用合成样本和模拟外部 API，无任何付费翻译请求。Windows 符号链接创建权限不足会跳过两项链接测试，移动和撤销真实文件操作已验证。macOS/Linux 由仓库 CI 矩阵验证，当前尚未运行远程 CI。
