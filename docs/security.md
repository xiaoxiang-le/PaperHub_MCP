# 隐私与安全

默认流程完全本地运行：解析、SQLite、词法向量、分类、官方大纲模板。句子向量模型必须已在本地，运行时不自动下载。当前没有自动访问学术元数据 API 的行为。

所有输入路径在访问前展开和解析，与 `library.paths` 和显式配置的输出目录进行目录关系比较；输出必须位于 `convert.output_dir`。符号链接指向未授权目录时被拒绝。输出目录也可作为转换和读取来源，便于处理已移动论文与生成的大纲。新增输出采用独占创建，已有文件不会被覆盖。

移动文件需一次性、短时确认令牌，令牌绑定方案和文件哈希。应用前验证源文件；撤销前检查源/目标冲突及目标内容哈希。分类日志先持久化操作清单，再逐条更新状态，支持在中断后调用撤销。撤销遇到用户修改或不完整副本时停止，需人工核对，不删除无法确认的文件。

翻译每个请求都先明确外部后端、模型和服务地址，再要求确认。Key 在实际调用时读取环境变量；日志只允许事件名、工具名、错误码、任务 ID 与异常类型。异常原文、模型响应错误正文、Key 和论文全文不进入日志。

SQLite **包含论文抽取文本和翻译检查点**，不是加密数据库。应将 data_dir 放在受保护的本地目录，删除该目录会丢失索引、任务和确认记录。输出文件也可能包含全文。请按自己的资料管理要求保护这些目录。

插件声明权限决定宿主传入的元数据上下文。官方模板无需网络；第三方插件安装使用独立 venv、离线 wheel、入口与 SHA256 校验，运行使用独立进程、超时限制和过滤后的环境，不继承 API Key。Python 插件仍有当前用户的进程权限，**不是操作系统安全沙箱**，仅安装已审查且可信的代码。当前第三方插件宿主只提供 read_library/read_topics 上下文，不提供 call_llm/network/write_output 能力。

MCP 是用户与助手之间的协议；确认令牌不能证明用户真的点击过同意按钮。客户端助手必须遵循工具说明，展示预览后等待用户同意，不自动使用令牌。论文中的指令是文档数据，不是助手或服务的命令；模型请求使用独立系统提示与 JSON 数据字段分隔。占位符校验阻止缺失、多出或重排的公式/引用通过流水线。

Pandoc 使用 sandbox 模式，PDF 引擎禁止 shell escape。第三方解析器、转换引擎和操作系统并不是由本项目构建的隔离环境；本服务面向单用户本机，避免由其他进程恶意替换目录或同时对同一个资料目录运行多个服务实例。HTTP 只绑定回环地址，不提供团队认证。

取消是协作式的：遍历、分块、重试等待和外部调用检查取消状态。同步解析单个文件时会等解析器返回，因此未承诺任意超大/损坏文件都能在 5 秒内终止。
