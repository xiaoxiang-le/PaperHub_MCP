# Changelog

## 0.1.0

- Python 3.11+ package with official MCP SDK, stdio/loopback HTTP, tools/resources/prompts.
- Local SQLite/FTS index and incremental four-format scanning with isolated failures.
- Classification preview, editable groups, index/symlink/move application and journaled undo.
- Offline TF-IDF baseline, optional strictly local sentence-transformers, HDBSCAN and fixed-count KMeans.
- Hybrid search, duplicate detection, BibTeX and CSL-JSON exports.
- Native PDF text extraction and guarded Pandoc/LibreOffice conversion routes.
- OpenAI/Anthropic adapters, external-transmission confirmation, formula/code/citation protection,
  chunk checkpoints, cancellation and translation resume.
- Permission-confirmed local outline plugins, trusted wheel installation in isolated environments,
  entry-point loading, timeout/crash isolation and outline editing/export.
- Unit/integration/real stdio protocol tests, cross-platform CI matrix and packaging metadata.
